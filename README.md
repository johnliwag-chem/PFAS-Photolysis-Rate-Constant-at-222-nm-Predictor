## Dataset Acknowledgment & Scientific Integrity
The MLR model deployed in this repository was trained using empirical PFAS photolysis data. The raw training data was sourced from the supplementary materials of the following peer-reviewed study:
Xin, X., Kim, J., Ashley, D. C., & Huang, C. (2023). Degradation and Defluorination of Per- and Polyfluoroalkyl Substances by Direct Photolysis at 222 nm. ACS ES&T Water, 3(8), 2776–2785. https://doi.org/10.1021/acsestwater.3c00274
